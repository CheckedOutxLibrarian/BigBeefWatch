# BigBeefWatch

Aiming to visualize Kendrick v Drake & Joey Bada$$ v Westcoast.

This repository contains a lightweight static web dashboard that compares the two rap matchups using stylized scorecards.

## Run locally

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` - main page
- `styles.css` - layout and styling
- `script.js` - matchup data and rendering logic
